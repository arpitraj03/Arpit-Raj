# StudyGenius – Your AI-Powered Study Assistant

**StudyGenius** is a smart, AI-driven web application designed to help students study more efficiently and effectively. Powered by the OpenAI API, it offers features like automatic note summarization, flashcard generation, quiz creation, and personalized study reminders.

## 🚀 Features
- ✍️ **Notes Summarizer** – Converts long notes into concise, understandable summaries.
- 🧠 **Flashcard Generator** – Creates flashcards to support active recall and memory.
- ❓ **Quiz Creator** – Instantly generates quizzes to test your understanding.
- ⏰ **Study Reminder Bot** – Helps schedule sessions and sends reminders to stay on track.

## 🛠️ Tech Stack
- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: Node.js  
- **AI Integration**: OpenAI API  
- **Platform**: Replit

## 📈 Future Scope
- User authentication & session management  
- Multi-language support  
- Analytics dashboard for tracking study progress
